🔑 What the Library Actually Outputs

Generated Keyframes Example (Draw Animation):

[ { offset: 0, strokeDashoffset: 1000 }, { offset: 1, strokeDashoffset: 0 } ] Animation Options: { duration: 1500, delay: 0, easing: "ease-out", direction: "normal", fill: "forwards", iterations: 1 }

💡 Performance Recommendations

✅ When Animatus SVG excels:

  • Complex SVG animations requiring multiple animation types
  • Auto-detection saves development time
  • Framework-agnostic (works with React, Vue, Angular)
  • Zero dependencies reduce bundle conflicts

⚠️ Consider alternatives when:

  • You need maximum performance (use CSS animations)
  • Bundle size is extremely critical (<10KB total)
  • Simple fade-in/out animations suffice
  • Working with very old browsers
